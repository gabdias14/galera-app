# Protótipo original

`galera-prototipo.html` é o protótipo de arquivo único que originou este projeto: HTML+CSS+JS puro,
sem build, com o estado inteiro numa variável em memória. Abrir no navegador ainda funciona.

Está aqui só como referência histórica — o design (cores, tipografia, carimbo de RSVP, aba perfurada
do ticket) foi portado tal e qual pra `src/styles/main.css`, e as views viraram os módulos em
`src/views/`. Nada em `src/` importa este arquivo.
